## 1. サービス定義

| 項目 | 内容 |
|---|---|
| 正式名称 | 健康チェックシステム |
| 提供元 | DAIYA INDUSTRY（bonboneブランド、© 2017） |
| ドメイン領域 | 接骨院・鍼灸院・整骨院／介護予防事業者向けの「体力測定 → 判定 → 運動処方 → 継続支援」プラットフォーム |
| ターゲット文脈 | 高齢者の**運動器機能向上（介護予防）** |
| 事業モデル | B2B SaaS マルチテナント（院＝テナント、院コードで識別、親院/子院の階層あり） |
| 主要ロール | 院スタッフ（本管理アプリを利用）。※患者は測定対象者としてスタッフが登録・管理する（自らはログインしない前提） |

**プロダクトの本質:**
患者の体力を測定 → 年代別標準値・サルコペニア基準・ランク判定基準で自動判定 → 6要素レーダーチャートで可視化 → 不足要素に応じたトレーニングを自動処方 → 今回/前回/初回の時系列で経過追跡。

### 3.13 プログラム作成ルール（推奨トレーニング自動処方の設定）
管理メニュー「トレーニングメニュー設定 > プログラム作成ルール」。測定結果から推奨トレーニングを自動生成する際に参照する **3種のメニュー設定**。

#### ① 固定メニュー設定
- 大人子供区分（大人 / 子供）で切替
- 表示順 1〜5 の枠に、トレーニングメニュー（項目名称 / 要素 / 部位 / 分類 / 回数時間 / セット数）を割当（編集 / 削除）
- → 測定結果に関わらず**常に処方する固定枠**

#### ② 年代別メニュー設定
- 年代区分（10代 / 20代 / … / 90代）ごと
- 表示順 1〜5 枠にトレーニングメニューを割当（編集 / 削除）
- → 年代に応じて追加処方するメニュー

#### ③ 要素別メニュー設定（自動処方の中核ルール）
- 「推奨メニューで更新する」ボタン（推奨値へ一括更新）
- 絞込軸: **要素区分**（筋力 / 筋持久力 / 柔軟性 / 敏しょう性 / バランス / 移動能力 / 瞬発力）× **部位区分**（上肢 / 下肢 / 全身）× **年齢区分**（大人 / 小学生低学年(6-7歳) / 小学生中学年(8-9歳) / 小学生高学年(10-11歳) / 中学生(12-14歳) / 高校生(15-17歳) / 未成年(18-19歳)）
- 一覧カラム: **トレーニングレベル** / トレーニング項目名称 / 分類 / 回数時間 / セット数（編集 / 削除）
- **トレーニングレベルは難易度順のはしご**（例: 筋力×上肢×大人 → Lv1 腕上げ → Lv3 壁押し → Lv6 腕立て伏せ → Lv10 腕立て伏せ(足上げ) と段階的に強度上昇）
- → 測定で判定した**要素別ランクに応じて、この「はしご」から適切なレベルの種目を選び自動処方**する仕組み

### 3.14 測定項目設定
- フィルタ: 測定分類（**バイタル / 形態 / 体組成 / 運動機能**）× 大人子供区分（大人測定 / 子供測定）
- 一覧カラム: ID / 測定項目名称 / 状態（使用中）/ 「使用切替」ボタン
- → 院ごとに測定項目のON/OFFを切替可能なマスタ

**測定項目マスタ（全分類 × 大人/子供、確認済み）:**

| 分類 | 大人測定 | 子供測定 |
|---|---|---|
| バイタル | 血圧 / 脈拍 | 血圧 / 脈拍 |
| 形態 | 身長 / 体重 | 身長 / 体重 |
| 体組成 | 体脂肪率 / 筋肉量 | 体脂肪率 / 筋肉量 |
| 運動機能 | 握力 / 立ち上がり / CS-30 / 長座体前屈 / 棒反応時間 / 閉眼片足立ち / 開眼片足立ち / FRT / 2ステップ / TUG / 5m歩行 / 反復横跳び | 握力 / 立ち上がり / 長座体前屈 / 棒反応時間 / 閉眼片足立ち / 上体起こし / 立ち幅跳び / 反復横跳び |

> **大人/子供で運動機能の項目が異なる**。子供特有: 上体起こし / 立ち幅跳び。大人特有: CS-30 / 開眼片足立ち / FRT / 2ステップ / TUG / 5m歩行。共通: 握力 / 立ち上がり / 長座体前屈 / 棒反応時間 / 閉眼片足立ち / 反復横跳び。

### 3.15 問診項目設定
- 一覧カラム: 問診項目名称 /「使用切替」ボタン
- **既定の問診項目（13件）**:
  1. 来院理由・目的
  2. 部位
  3. 症状
  4. 発症日（あるいは負傷日）
  5. 負傷場所
  6. 負傷原因
  7. 同一症状での他の医療機関への受診
  8. 他の傷病（治療中 or 既往）
  9. 手術歴
  10. 服薬状況
  11. 湿布やテーピング等によるかぶれの経験
  12. 【女性のみ】妊娠またはその可能性
  13. その他、不安な点や困っていること

### 3.16 データの書き出し
- データ名称ごとに「ダウンロード」ボタン（CSV等のエクスポート）。書き出し対象＝内部データエンティティの手がかり:
  - サルコペニア基準値
  - 年代別標準値
  - ランク判定基準値
  - トレーニングメニュー情報
  - 固定メニュー設定
  - 年代別固定メニュー設定
  - 要素別メニュー設定
  - 院情報
  - **子院情報**（→ 親子院の階層構造）
  - スタッフ情報
  - 患者情報

### 3.17 患者詳細検索
モーダルで高度な検索。分析用途。

- **基本情報**: ゲストを含む / 氏名 / カナ氏名 / 性別 / 生年月日（範囲）
- **カード情報**: 保険証番号 / 診察券番号
- **住所** / **連絡先**（電話 or 携帯 / メール / FAX）
- **属性情報**: 要介護度区分（範囲）/ 職業 / 運動習慣 / 家族環境
- **来院・測定情報**: 来院日（初回・最終、範囲）/ 測定日（初回・最終）/ 更新日（初回・最終）/ 測定有無（分類×日付×あり/なし）/ 来院回数（範囲）/ 測定回数（範囲）
- **表示順**: 優先順位1〜3（項目×昇順/降順）
  - ソート可能項目: 氏名 / カナ氏名 / 性別 / 生年月日 / 保険証番号 / 診察券番号 / 住所 / 電話番号 / 携帯電話番号 / メールアドレス / FAX番号 / 要介護度 / 職業 / 運動習慣 / 初回来院日 / 最終来院日 / 初回測定日 / 最終測定日 / 初回更新日 / 最終更新日 / 来院回数 / 測定回数

> 派生・集計項目（来院回数・測定回数・初回/最終来院日・初回/最終測定日）が存在することが分かる。

### 3.18 院内掲示板 一覧／登録
- 一覧: 検索（掲載日から / キーワードから）＋「新規登録」＋検索結果一覧
- 登録フォーム: タイトル【必須】/ 詳細メッセージ / 掲載開始日【必須】/ 掲載終了日【必須】/ 登録
- → 掲載期間を持つ院内向けお知らせ（スタッフ向け情報発信）

### 3.19 診療カレンダー設定
- 「新規登録」＋月間カレンダー（前月/次月ナビ）
- 各日に「診療日（時間帯）」または「休診日」を表示。施設情報の曜日別診療時間をベースに、日ごとの例外（休診日・特別時間）を登録
- 検索条件: 年月 / 名称

## 7. 自作サービス構築の重要ポイント

1. **マルチテナント＋RBAC が土台**
   院単位のデータ分離＋親子院階層。スタッフ権限3段階（特に「個人情報閲覧不可」ロールは医療・介護系で必須）。
2. **測定項目・問診項目・トレーニングメニューをマスタ化**（使用ON/OFF切替）
   院ごとにカスタマイズできる設計。子供測定/大人測定の切替も。
3. **判定ロジックが差別化の核**
   「年代別標準値」「サルコペニア基準」「ランク判定基準」をデータ駆動のルールテーブル化。測定値→ランク→不足要素→推奨メニューを自動生成（固定/年代別/要素別メニュー設定）。
4. **時系列比較（今回/前回/初回）＋レーダー可視化**
   運動器年齢・6要素チャートで改善を可視化＝継続来院の動機付け。
5. **日本の高齢者向けUI配慮**
   生年月日の和暦セレクト（大正〜令和）、介護予防（運動器機能向上）文脈。
6. **入力の堅牢性**
   各測定項目に「測定不可」フラグと複数試行（握力2回・棒反応5回など）＋備考。一時保存対応。
